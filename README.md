# Financial Complaint Index

A large-scale search and information retrieval system for millions of public consumer complaints from the Consumer Financial Protection Bureau (CFPB).

## Project status

Currently in development.

## Purpose

The project will allow analysts and researchers to efficiently search, filter, and examine CFPB consumer complaints by company, financial product, issue, location, date, company response, and complaint narrative.

## Planned capabilities

- Full CFPB dataset ingestion
- PostgreSQL database storage
- Structured SQL filtering
- Full-text narrative search
- Database indexing and performance benchmarks
- Search API
- Automated tests
- Simple analyst-facing interface

## Data source

Consumer Complaint Database published by the Consumer Financial Protection Bureau:

https://www.consumerfinance.gov/data-research/consumer-complaints/

## Development approach

The system is being built incrementally: define, research, design, build, test, document, deploy, and measure.
